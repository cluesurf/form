# The shared model

The shared model of form.surf: the claims that two or more model
repositories share, worded neutrally, every contradiction between them
kept visible as open claims, and the recorded failures of every framework
as rejected claims. Format: form.surf/1.

Every record here is AI-written and unreviewed. Each one names, in
`origin`, the model repository records it was drawn from. Nothing here
is endorsed by the originators of any framework.

## Standing

- **open**: the default. Plausible, incomplete, disputed or untested.
- **integrated**: needs recorded evidence or a derivation and an accepted
  proposal. None is integrated yet. The seed proposal
  (`proposal/seed.json`) proposes integration for the claims listed in
  `paper/review-list.md`, pending review.
- **rejected**: needs a recorded failure, and keeps it written down.

Agreement among frameworks is a lead, never proof. No field counts votes.

## Correcting it

Open a proposal: a pull request whose diff includes a `proposal/` record.
This folder is regenerated from the model repositories. Propose a
correction as a pull request, and it is carried into the next generation.
