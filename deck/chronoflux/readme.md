To propose a correction, open an issue or a pull request that changes the record in question, citing the source and locator that shows the error. A correction from Roy D. Herbert is especially welcome.

Roy D. Herbert's program in which covariant continuity, a conserved temporal current, is the one primitive physical law, and relativity, gravity, quantum mechanics, thermodynamics, fluids and cosmology are recovered from it by a ladder of admissibility conditions.

This is a form.surf model repository (format `form.surf/1`). It holds the framework's own claims, each as one JSON record in `proposition/`, and the relations between them in `link/`. Every record names its sources in `provenance.sources`, with a locator and, where it could be checked, a short verbatim quote. `paper/account.md` is the plain account.

## Labels

- `provenance.ai_written: true`: a model extracted the record from the cited source.
- `provenance.reviewed: false`: no person has yet read the record against its source.
- `status: "superseded"`: a claim the author withdrew or replaced in his July 2026 Version 2.0 rebuild. Each is joined by a `supersedes` link to the claim that replaced it, and listed under `atlas.dead_ends`.
- `standing: "open"`: set on the boldest claims (the Millennium Problems, Navier-Stokes, inertia engineering, biology, the dark sector, the fine-structure constant), each with the author's own grading in its reason. No test has decided any of them.
- `prediction`: the four pre-registered falsifiers. Every `outcome` is null, since no source reports one.
- There are no `observation/` records and no `voice: "critique"` claims: no source reports an outcome for a Chronoflux prediction, and no published criticism of the framework was found.
