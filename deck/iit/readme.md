# Integrated Information Theory

Community-written from public sources, AI-extracted, unreviewed. This
repository is not written or endorsed by Giulio Tononi, Christof Koch or
their collaborators. Every record was extracted by a model
(`claude-opus-5-5`) from the papers listed in `source/`, and no person
has yet checked a record against its source. To propose a correction,
open an issue or a pull request that changes the record and cites the
page or section of the source.

This is a form.surf model repository (format `form.surf/1`) stating
integrated information theory in its own terms: the IIT 4.0 axioms and
postulates, the explanatory identity, its predictions about the brain,
the 2025 adversarial test, and the published criticisms as open claims.

- `paper/account.md`: the theory in plain words
- `proposition/`: one claim per file. `voice: "critique"` marks a
  published criticism
- `observation/`: the evidence the theory cites and the evidence against it
- `link/`: how claims depend on and bear on each other
- `source/`: the papers, each with a DOI, PubMed id, arXiv id or URL

Check it with `form check deck/iit` from the root of the form repository.
