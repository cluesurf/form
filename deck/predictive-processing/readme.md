# predictive-processing

**Community-written from public sources. AI-extracted (claude-opus-5-5) and unreviewed. Not written or endorsed by Anil Seth or his collaborators.** To propose a correction, open an issue or a pull request that changes the record and cites the source passage, page or section included. Every record lists its sources in `provenance.sources`.

A form.surf model repository for Anil Seth's predictive processing account of consciousness and the self: perception as controlled hallucination, emotion and selfhood as interoceptive inference, and the beast machine view that consciousness is grounded in being alive. Andy Clark and Jakob Hohwy develop related predictive processing views, which appear here only as related sources.

- `paper/account.md`: the account in plain words, linked to its claims
- `proposition/`: the claims, one per file, with `voice: "critique"` for published criticism
- `observation/`: evidence the account cites and evidence against it
- `link/`: dependencies, support, objections and questionnaire answers
- `source/`: the papers and essays every record cites

Format: form.surf/1. Check with `form check .`. License CC-BY-4.0 for these records. The quoted passages belong to their authors.
