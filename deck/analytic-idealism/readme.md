# Analytic idealism

Community-written from public sources, AI-extracted, unreviewed. Not written or endorsed by Bernardo Kastrup. To propose a correction, open an issue or pull request that changes the record and cites the source.

This is a [form.surf](https://form.surf) model repository for analytic idealism, the ontology of Bernardo Kastrup: there is only cosmic consciousness, and individual minds are dissociated alters of it. Each claim is one JSON record in `proposition/`, with its kind (definitional, empirical, philosophical, normative), its epistemic status, and the source and page it was taken from. Most claims are philosophical. The empirical bridges Kastrup draws (dissociative identity disorder, psychedelic neuroimaging, brain function impairment, quantum foundations) are marked empirical. Evidence is in `observation/`, and `link/` joins claims to each other and to evidence. Published criticisms, and the objections Kastrup answers, are kept as claims with `voice: "critique"`.

Every record has `provenance.ai_written: true` and `reviewed: false` until a named person checks it against its sources.

Format: form.surf/1. Check with `form check .`.
