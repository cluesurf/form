# Conscious Agents

**Community-written from public sources, AI-extracted, unreviewed, and not written or endorsed by Donald Hoffman or his collaborators.** To propose a correction, open an issue or a pull request that changes the record and cites the source passage.

A form.surf model repository: the claims of Donald Hoffman's interface theory of perception and his theory of conscious agents (conscious realism), with Chetan Prakash, Manish Singh, Chris Fields and Robert Prentner, stated as its originators state them in their published papers.

## What is here

- `proposition/`: the framework's claims, one per file, in three clusters: the interface theory with its fitness theorems, conscious realism and the conscious agent formalism, and the Fusions of Consciousness work on spacetime and particles. Published criticisms are `voice: "critique"`. Answers to the nine form.surf questions start with "Answer:".
- `observation/`: the simulations and proofs the framework cites, and the evidence against it.
- `link/`: dependencies (`requires`, `assumes`) and evidence (`supports`, `weakens`).
- `source/`: every paper cited, each opened and checked when this was written.
- `paper/account.md`: the framework in plain words.

## How to read the labels

- **epistemic_status**: how the claim was reached (inferred for proofs, simulated for game results, hypothesized for proposals).
- **standing**: left empty. This repository records claims, it does not rule on them.
- **provenance.ai_written: true, reviewed: false** on every record: a model extracted it and no person has yet checked it against its source.

## Corrections

Every record cites its source with a locator and, where checked, a short verbatim quote. If a record misstates the framework, open an issue or pull request with the passage that shows it. Format: form.surf/1, specified at https://form.surf/guides/developers/format.
