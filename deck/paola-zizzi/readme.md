# Quantum-computing universe (Zizzi)

**Community-written from public sources, AI-extracted (claude-opus-5-5), unreviewed. Not written or endorsed by Paola A. Zizzi.**
To propose a correction, open an issue or a pull request that changes the record in question, citing the source and locator that shows the error. A correction from Paola A. Zizzi or their collaborators is especially welcome.

Paola Zizzi's program in which Planck-scale space-time is a quantum computer whose pixels of area each hold a qubit, the inflationary universe is that computer growing until it self-reduces by Penrose's objective reduction, and that reduction is a conscious event of the same kind as a human one.

This is a form.surf model repository (format `form.surf/1`). It holds the framework's own claims, each as one JSON record in `proposition/`, with the evidence its originators cite and the evidence against it in `observation/`, the published criticism as propositions with `voice: "critique"`, and the relations between them in `link/`. Every record names its sources in `provenance.sources`, with a locator and, where it could be checked, a short verbatim quote. `paper/account.md` is the plain account.

## Labels

- `provenance.ai_written: true`: a model extracted the record from the cited source.
- `provenance.reviewed: false`: no person has yet read the record against its source.
- `voice: "critique"`: a published objection, not the framework's own claim.
- `standing`: null on every claim. The program is theoretical and its conjectures carry no recorded test.
