# Present-state theory (Mallavarapu and Percy)

**Community-written from public sources, AI-extracted (claude-opus-5-5), unreviewed. Not written or endorsed by Aneil Mallavarapu and Chris Percy.**
To propose a correction, open an issue or a pull request that changes the record in question, citing the source and locator that shows the error. A correction from Aneil Mallavarapu and Chris Percy is especially welcome.

Aneil Mallavarapu and Chris Percy's no-go theorem for process theories of consciousness (PsyArXiv preprint, version 1, August 10, 2026): if a system's present state and inputs fix its future, and consciousness makes a difference, then consciousness depends only on the present state, not on the process that produced it.

This is a form.surf model repository (format `form.surf/1`). It holds the paper's own claims, each as one JSON record in `proposition/`, the proof and a documentary record in `observation/`, and the relations between them in `link/`. Every record names its sources in `provenance.sources`, with a locator and, where it could be checked, a short verbatim quote. `paper/account.md` is the plain account.

## Labels
