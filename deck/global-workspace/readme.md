# Global Workspace Theory

Community-written from public sources, AI-extracted, unreviewed. Not written or endorsed by Bernard Baars, Stanislas Dehaene, Jean-Pierre Changeux or Lionel Naccache. To propose a correction, open an issue or pull request that changes the record and cites the source.

This is a [form.surf](https://form.surf) model repository for global workspace theory (Bernard Baars) and the global neuronal workspace (Stanislas Dehaene, Jean-Pierre Changeux, Lionel Naccache). Each claim is one JSON record in `proposition/`, with its kind (definitional, empirical, philosophical, normative), its epistemic status, and the source and page it was taken from. Evidence is in `observation/`, and `link/` joins claims to each other and to evidence. Published criticisms are kept as claims with `voice: "critique"`.

The results of the 2025 Cogitate adversarial collaboration are recorded as observations, shared with the integrated information theory repository. Two preregistered predictions that failed are marked rejected, with the observation that failed them.

Every record has `provenance.ai_written: true` and `reviewed: false` until a named person checks it against its sources.

Format: form.surf/1. Check with `form check .`.
