# Invariant set theory

**Community-written from public sources, AI-extracted (claude-opus-5-5), unreviewed. Not written or endorsed by Tim N. Palmer.**
To propose a correction, open an issue or a pull request that changes the record in question, citing the source and locator that shows the error. A correction from Tim N. Palmer is especially welcome.

Tim N. Palmer's invariant set theory (IST), developed from 2008 to 2022, partly with Sabine Hossenfelder and Jonte Hance: the universe evolves deterministically on a fractal invariant set of measure zero in its state space, the geometry of that set is the most basic law, and states off the set, including many counterfactual ones, are not physical. From this Palmer reads quantum complementarity, a locally causal account of Bell violation through a violation of Statistical Independence (superdeterminism), a finite discretized Hilbert space whose singular limit is quantum mechanics, a top-down approach to quantum gravity with no graviton, and a definition of consciousness as awareness of nearby counterfactual worlds. Indrajit Sen's published critique and the reply to it are recorded.

This is a form.surf model repository (format `form.surf/1`). It holds the framework's own claims, each as one JSON record in `proposition/`, and the relations between them in `link/`. Every record names its sources in `provenance.sources`, with a locator and, where it could be checked, a short verbatim quote. `paper/account.md` is the plain account.

## Labels

- `provenance.ai_written: true`: a model extracted the record from the cited source.
- `provenance.reviewed: false`: no person has yet read the record against its source.
- `epistemic_status: "inferred"` marks a result the papers derive from the invariant set geometry. `hypothesized` marks a postulate or a speculation, which is how the consciousness and creativity claims are offered.
- `prediction`: the time-correlation test proposed with Sabine Hossenfelder. Its `outcome` is null, since no source reports the experiment done.
- `voice: "critique"`: Indrajit Sen's published hidden-variable analysis, joined by `contradicts` to the claim it targets, beside the reply by Hance, Hossenfelder and Palmer.
